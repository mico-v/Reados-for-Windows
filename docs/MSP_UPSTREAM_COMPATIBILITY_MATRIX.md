- `conformant`: the adopted scope passes the selected upstream evidence with no known deviation.

## Public FFI release boundary


`native/msp-ffi` is a separate ReadOS-owned public C ABI wrapper, not the internal `reados-msp-native/1` adapter and not a claim that the blocked upstream Windows source package has been reproduced. Its release metadata records the `x86_64-pc-windows-msvc` release manifest, `msp_ffi.h` hash, DLL hash, static MSVC CRT requirement, and exactly 29 exports. `scripts/verify-msp-ffi-release.ps1` parses the PE export/import directories and checks that contract. `scripts/package-windows.ps1` builds and copies `msp_ffi.dll` plus `include/msp_ffi.h` only with `-IncludePublicMspFfi`; the default package, `msp_core.dll`, and app smoke remain unchanged. Package verification rejects raw `MSP/`, source/private state, PDBs, linker outputs, and other generated build files.

The separate `scripts/verify-msp-ffi-multiarch.ps1` check maps `win-x64` to `x86_64-pc-windows-msvc`/PE `0x8664` (AMD64), `win-x86` to `i686-pc-windows-msvc`/PE `0x014C` (I386), and `win-arm64` to `aarch64-pc-windows-msvc`/PE `0xAA64` (ARM64), including the PE32/PE32+ optional-header distinction. ## Intentional ReadOS domain exclusions

PDF parsing/rendering, document models, chat/provider calls, credentials, workflow orchestration, artifact lineage presentation, workspace-state persistence and WinUI remain in `ReadOS.App`. Rust may expose generic workspace, execution and audit primitives to those features, but it must not absorb their domain implementations or secrets.
