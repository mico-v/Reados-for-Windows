# ReadOS virtual-workspace command pack

This ReadOS-owned crate provides bounded, deterministic `pwd`, `echo`, `cat`, `ls`, `du`, and `find` commands plus safe virtual-workspace subsets of `printf`, `head`, `tail`, `wc`, and literal-byte `grep` over the `msp-backend::WorkspaceBackend` trait. It preserves binary bytes and explicit empty arguments, rejects host-shaped paths, and never reads host process, environment, or filesystem state or starts a process.

`du` is a metadata-only logical-byte command. It supports `-a`/`--all`, `-s`/`--summarize`, `-b`/`--bytes`, and `--`; omitted operands use the virtual cwd. Default output reports directory totals postorder, `-a` also reports files, and `-s` reports only each operand total. Totals sum checked `WorkspaceEntry::size` values and print decimal bytes followed by canonical virtual paths. It does not infer blocks, physical disk usage, timestamps, ownership, host paths, or filesystem capacity. Formatting, inode, block, filesystem, and dereference options are rejected, including options for which the backend has no usage capability. `.msp` components are filtered, recursion, metadata entries, scanned path bytes, output, and cancellation are bounded, and diagnostics are fixed and path-free.

`find` is metadata-only: it accepts one virtual start path (or the virtual cwd) and implicit-AND `-name PATTERN`, `-iname PATTERN`, and `-type f|d` predicates. Name patterns are bounded literals with only `*` and `?`; traversal is sorted by canonical virtual path, skips `.msp` components, and never opens or follows entries. `-exec`, `-ok`, `-delete`, `-print`, and unsupported expression/options are rejected with fixed path-free diagnostics. Recursion, metadata entries, pattern bytes, aggregate scan bytes, output, and cooperative cancellation are bounded.

`grep` accepts only explicit `-n`, `-i`, `-v`, `-c`, `-l`, `-q`, and one `-r` option, followed by a bounded literal pattern and virtual file operands or `-` stdin. It uses a linear-time KMP byte matcher, ASCII-only case folding, 32 KiB-or-backend range reads, line state that crosses chunks, deterministic metadata recursion, and fixed diagnostics. Regular expressions, shell forms, host paths, and unsupported options are rejected. Recursive traversal skips `.msp` components and is bounded by entry, depth, read, output, and aggregate scan limits.

`printf` renders the supported byte-safe escape and format conversions without locale or shell behavior. `head` and `tail` provide bounded byte/record selection with explicit stdin, virtual paths, zero-terminated mode, headers, and fixed rejection of follow/watch features. `wc` streams bounded virtual ranges and counts LF lines, ASCII-whitespace words, and bytes with saturating counters. File ranges are at most 32 KiB and command scans have an aggregate bound.

The implementation is an authored adaptation informed by public MSP specifications and conformance descriptions. It contains no raw MSP source and has no MSP dependency.
